# Info Collector

把散落在网页和书签里的优质内容，整理成可搜索、可回顾的中文知识库。

[在线体验阅读桌](https://info-collector-reading-desk.jiligualapiqiu.chatgpt.site/)

## 它能为你做什么

- **一键收集**：在 Chrome 保存当前文章，也可以批量导入书签。
- **快速读懂**：把长文整理成中文译文、摘要和标签，先抓重点，再读全文。
- **集中管理**：在一个阅读桌里搜索、筛选、收藏和整理所有文章。
- **持续沉淀**：保留原文链接与 Markdown 归档，逐步建立自己的知识库。
- **高效回顾**：一键导出每周阅读回顾，让收藏真正转化为可复用的知识。
